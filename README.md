Tiny Script which aim to make project setup easier

- Git Initializer
- MERN React Initializer (React + Node.js with various features like Taliwind-css, eslint, passport.js, prisma)
- React + DJango Backend (Setup React for DJango Backend and React Fontend)
- React with Tailwind (only Frontend)
- gitignore generate (uses toptal's API begind the scene)
- Weather Report for you location
- File Organizer
- node_modules cleaner (urgent need of this)
